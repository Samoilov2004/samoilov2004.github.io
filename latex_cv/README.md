# CV sources

ATS-friendly, single-column CVs in English and Russian.

Build both PDFs from the repository root:

```sh
make -C latex_cv
```

The website links to:

- `Mikhail_Samoilov_CV_EN.pdf`
- `Mikhail_Samoilov_CV_RU.pdf`

Before using the CV for applications, confirm the degree statuses and replace the general Yandex bullets with measurable outcomes where disclosure is permitted.
